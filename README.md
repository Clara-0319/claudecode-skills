# Claude Code Skills

> 精选 Claude 高能技能合集，帮助你更聪明地思考、工作和决策

一套深度定制的 AI 对话技能，每个都是针对特定场景的专家级工具。无论是学术写作、生涯探索、问题求解，还是团队管理，这里都有一个为你量身定做的技能。

## 🎯 核心技能库

### 1. **论文批判性审查** (`check-paper`)

> 像 SCI 核心期刊高级编辑一样审视学术论文

**用途**：
- 帮助研究者发现论文中的逻辑漏洞和证据不足
- 系统化审查论文的前提、证据、推理链条
- 生成专业的学术审稿意见

**工作流程**：
1. **前提识别** - 找出论文的核心假设，区分显性和隐含前提
2. **充要性评估** - 分析前提能否充分支撑结论
3. **证据审查** - 逐一评估证据的真实性和支撑力度
4. **逻辑跳跃检测** - 发现论证中的断层和不合理推论
5. **可证伪性分析** - 说明什么情况下论文结论会被推翻

**输出**：结构化的 `.md` 审查报告

**适用场景**：
- 投稿 SCI 期刊前的自审
- 研究生学位论文的质量把关
- 学术工作坊和论文讨论会

---

### 2. **天赋挖掘机** (`dig-what-you-are`)

> 通过苏格拉底式对话，发现你的底层天赋和内在热爱

**用途**：
- 帮助职场人士（尤其是迷茫期）重新认识自己
- 挖掘那些被压抑、被低估的天赋
- 生成个性化的《天赋使用说明书》

**工作流程**：
1. **沉浸时刻** - 探索 16 岁前废寝忘食做的事
2. **无意识胜任区** - 发现你觉得简单但别人觉得难的能力
3. **心流验证** - 找出让你"回血"的事
4. **嫉妒信号** - 追踪那些被压抑的渴望

**输出**：精美的 HTML 网页报告，包含：
- 四个维度的深度分析（思维模式、盲区、潜能、热爱）
- 三维内在资源图（知识/能力/经历）
- 具体的行动建议

**适用场景**：
- 职业方向迷茫的人
- 想了解自己真正热爱的人
- 生涯咨询和个人发展规划

---

### 3. **内在资源探索** (`inner-gift`)

> 深度苏格拉底式对话，触碰潜意识中的天赋信号

**用途**：
- 比"天赋挖掘机"更深层的个人探索
- 发现那些连你自己都没意识到的核心模式
- 理解你做每件事背后真实的驱动力

**工作流程**：
至多 30 轮一问一答的深度对话：
- **表层（第 1-5 轮）** - 建立信任，收集素材
- **中层（第 6-14 轮）** - 进入价值系统，探索选择逻辑
- **深层（第 15-23 轮）** - 触碰核心信念和假设
- **潜意识层（第 24-30 轮）** - 挖掘被压抑的信号

**输出**：设计精美的 HTML 报告，包含：
- 思维模式与反复出现的主题
- 盲区与自我欺骗
- 尚未触及的潜能
- 内在资源三维图
- 底层天赋图谱（12 个维度）
- 2-3 个值得探索的人生方向

**适用场景**：
- 深度生涯咨询
- 个人转型和重新定位
- 人生重要决策前的自我认知

### 4. **多学科视角问题求解** (`multi-perspective`)

> 汇聚各领域顶级专家，用跨学科创新思维解决复杂问题

**用途**：
- 突破单一学科思维局限
- 为技术、管理、工程等复杂问题寻找创新方案
- 发现看似不相关领域中隐藏的解决方案

**工作流程**：
1. **问题解构** - 识别核心挑战，明确为何需要多学科视角
2. **多专家分析** - 邀请 3-5 位来自不同领域的专家独立分析
   - 核心挑战识别
   - 创新解决方案
   - 可行性验证
3. **跨学科融合** - 整合各方案中最有价值的元素

**可选专家领域**：
- 数学家（抽象建模、优化理论）
- 物理学家（能量转换、系统动力学）
- 化学家（分子设计、材料合成）
- 生物学家（仿生设计、生态思维）
- 管理学家（组织行为、商业模式）
- 工程控制专家（系统集成、反馈机制）
- 经济学家（激励机制、博弈论）

**输出**：综合方案，包含：
- 各专家独立视角和方案
- 跨学科协同效应分析
- 权衡取舍建议
- 融合落地路径

**适用场景**：
- 固态电池等材料科学难题
- 城市交通、资源配置等系统问题
- 团队管理、组织变革等管理问题
- 任何需要创新突破的复杂问题

## 🚀 快速开始

### 如何使用这些技能？

每个技能都是独立的模块，可以在 Claude 对话中直接调用：

1. **论文审查**
   ```
   帮我审一下这篇论文，我需要投 SCI 期刊：
   [论文摘要和片段]
   ```

2. **天赋挖掘**
   ```
   帮我挖掘自己的天赋，生成天赋报告
   ```

3. **问题求解**
   ```
   用多学科视角帮我分析这个问题：
   [复杂问题描述]
   ```

## 🎓 背景理论

- **论文审查**：结合学术规范和批判性思维框架
- **天赋挖掘**：基于盖洛普优势理论（StrengthsFinder）和心流理论（Csikszentmihalyi）
- **内在资源**：融合盖洛普理论、心流理论与荣格心理学
- **多学科求解**：跨学科思维和系统创新方法

## 💡 核心哲学

- **天赋永不过期** - 你的底层天赋不会因为选择而消失

- **跨界即创新** - 最好的解决方案往往来自看似无关的领域
- **学术严谨性** - 批判性思维是发现真理的基础
